# **Student Dashboard**

A student dashboard project built to help organize schoolwork and present important academic information in one place. I created this project to improve my web development skills and get more practice with HTML, CSS, and responsive web design.

## **About the Project**

The goal of this project was to build a clean and organized dashboard for students. I focused on the layout, spacing, and overall design to make the dashboard easy to navigate and use on different screen sizes.

This project has also helped me improve my CSS skills as I worked with layouts and turning a design idea into a working webpage.

## **Technologies Used**

HTML5 – Used to structure the webpage and its content.

CSS3 – Used for styling, layouts, spacing, and responsive design.

CSS Grid and Flexbox – Used to organize dashboard sections and align elements.

Media Queries – Used to adjust the layout for different screen sizes.

# **What I Learned**

While working on this project, I improved my understanding of:

- Creating layouts with CSS Grid and Flexbox.
- Making webpages responsive for various screen sizes.
- Organizing HTML and CSS code.
- Using spacing, alignment, and typography to improve the user interface.
- Debugging layout issues and making adjustments as I build.
